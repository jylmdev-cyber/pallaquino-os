# Soporte

- **Errores reproducibles:** abre un Bug report usando la plantilla de Issues.
- **Mejoras:** utiliza Feature request y explica beneficio, alcance y alternativas.
- **Preguntas de uso:** abre un Issue de discusión hasta que GitHub Discussions
  esté habilitado.
- **Vulnerabilidades:** sigue [SECURITY.md](SECURITY.md); nunca uses un Issue.

Incluye versión de PALLAQUINO, sistema operativo, versión de Python, comando
ejecutado, salida sanitizada y ejemplo mínimo. No compartas tokens, `.env`, datos
personales ni contenido confidencial.

El soporte comunitario se presta según disponibilidad y no constituye un SLA.
