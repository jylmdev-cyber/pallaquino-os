Todo el código está en `universal_ai_fullstack_orchestrator/pallaquino_cli/` y usa solo la biblioteca estándar.

| Paquete o módulo | Responsabilidad |
|---|---|
| `__main__.py`, `cli_orchestration.py`, `cli_platform.py` | Definición de la CLI (argparse) y despacho de comandos |
| `core.py` | Raíz del framework, validadores, riesgo, identidad, init, checkpoints y handoffs |
| `contracts.py` | Contratos v2 de agentes y skills: derivación y validación |
| `orchestration/` | `intent` (intención), `routing` (agentes), `planning` (DAG), `scheduler`, `executors`, `observability` |
| `memory/` | Memoria del proyecto en SQLite (`store.py`) |
| `providers/` | Interfaz de proveedores, `mock`, `ollama` y router |
| `tools/` | Registro, esquemas, permisos, enrutamiento y pasarela de herramientas |
| `mcp/` | Cliente y servidor MCP, transportes, autenticación y política de red |
| `extensions/` | Descubrimiento, manifiesto, versión y gestión de plugins |
| `integrations/` | Adaptadores de sistema de archivos, Git, SQLite y GitHub |
| `sdk/` | SDK de plugins: andamiaje, ejecución aislada y utilidades de prueba |

## Principios

- **Sin dependencias de ejecución**: solo la biblioteca estándar de Python 3.11+.
- **Neutralidad de proveedor**: el motor no depende de ningún modelo concreto.
- **Denegación por defecto** para herramientas; los datos externos nunca son instrucciones.
- **Evidencia antes que afirmaciones**; lo inferido se marca `RECONSTRUCTED`.
- **Generadores en seco por defecto**: los scripts que reescriben archivos exigen `--write`.

Las decisiones están registradas como ADR en `docs/adr/` (de ADR-0001 a ADR-0016) y la arquitectura en `docs/ARCHITECTURE.md` y
`docs/architecture/`.

<Aside type="tip">
	Antes de cambiar el núcleo, ejecuta `python scripts/architecture_fitness.py`: comprueba las reglas de arquitectura de
	`architecture/fitness_rules.json`.
</Aside>
