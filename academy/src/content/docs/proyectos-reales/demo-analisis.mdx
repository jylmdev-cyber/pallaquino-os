Desde `universal_ai_fullstack_orchestrator`:

```bash
python scripts/run_codebase_analysis_demo.py
```

La demo procesa la solicitud *"Analiza el repositorio actual, identifica problemas de calidad, revisa el estado de Git y genera un informe
técnico"*. Por dentro:

1. inicializa un proyecto desechable con `init` (no escribe estado en el repositorio analizado);
2. configura, revisa, clasifica y fija el servidor MCP de prueba;
3. crea un grant acotado;
4. planifica y ejecuta, con las herramientas de Git, sistema de archivos y MCP pasando por la pasarela;
5. comprueba el informe, la auditoría, las métricas y la memoria;
6. compara el `git status` del repositorio analizado antes y después.

Sin claves de API, sin red y sin servicios comerciales.
