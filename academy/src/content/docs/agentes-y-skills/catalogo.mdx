El explorador lee los datos generados del registro (`registry/agents.json`, `registry/skills.json` y sus contratos). No hay ningún
agente escrito a mano en este portal.

<AgentExplorer client:load />

Lo mismo desde la CLI:

```bash
python -m pallaquino_cli agents list --json
python -m pallaquino_cli skills list --json
```

## Ejercicios

1. Filtra por la categoría **security**. ¿Qué agente revisa infraestructura?
2. Busca `migration`. ¿Qué agentes y skills aparecen y qué límite de riesgo tienen?
3. Elige un agente que pueda desplegar (`can_deploy`). ¿Qué herramientas requieren aprobación?
