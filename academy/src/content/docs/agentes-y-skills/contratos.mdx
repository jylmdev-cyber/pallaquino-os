## Curado frente a derivado

```bash
python -m pallaquino_cli contracts --json
```

- **Curados**: escritos y revisados a mano. Hoy, 13 contratos de rol de agentes.
- **Derivados**: generados a partir del registro (el resto de agentes y todas las skills).
- **untested**: contratos sin casos de prueba propios. La lista es pública en la salida; no se oculta.

Un contrato no autoriza nada por sí mismo: las herramientas siguen pasando por la pasarela de permisos (ruta 7).
