## Códigos de salida

| Código | Significado |
|---:|---|
| 0 | Completado / correcto |
| 1 | Fallo o error |
| 2 | Raíz del framework no encontrada (también, argumentos no válidos) |
| 3 | Esperando aprobación o en pausa |
| 4 | Cancelado |
| 5 | Permiso denegado por la pasarela de herramientas |
